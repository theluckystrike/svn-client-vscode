# Changelog

## 0.1.0

- First release. Source Control for svn working copies: commit, update, revert, add, delete, ignore, resolve, cleanup and changelists.
- Diff against BASE and gutter marks, log view with filters and paging, blame in the editor.
- Switch, branch, tag and merge with a dry run and the exact command shown first.
- One svn status at a time per working copy, nested working copies found once, an install page when svn is missing.
- Revision graph, shelving and the changelist manager (free in this version).
- Zovo Pro text (not active in this version) now says USD 19 once on the Zovo Pro Sponsors tier; the shared Sponsors check counts only that tier or an active monthly tier of USD 10 or more.
