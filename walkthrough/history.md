# History

"SVN: Show Log" lists the revisions of the working copy, 100 at a time. "Show File History" in the editor or Explorer menu does the same for one file or folder.

- Filter by text, author and date. The search runs in svn (`svn log --search`), so it covers the whole history.
- Click a revision to see its message and changed paths. Click a path to see its diff.
- Tick two revisions and press Compare to see what changed between them.
