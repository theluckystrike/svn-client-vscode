# The svn command line

SVN Client runs the `svn` program that is installed on your computer. It bundles none and downloads none.

- macOS: `brew install subversion`
- Debian and Ubuntu: `sudo apt install subversion`
- Windows: TortoiseSVN with "command line client tools", or SlikSVN

If svn is installed but not found, set its full path in the setting `zovoSvn.path`.
